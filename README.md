## 📌 Overview

AI Career Intelligence Engine is an AI-powered web application that helps users make informed career decisions through intelligent resume analysis, career recommendations, and skill-gap identification.

The platform leverages Large Language Models (LLMs) and modern AI techniques to provide personalized insights that help students and professionals improve their employability.

---

## ✨ Features

- 📄 Resume Analysis
- 🤖 AI Career Recommendations
- 🎯 Skill Gap Analysis
- 📊 Resume Scoring
- 💡 Personalized Improvement Suggestions
- 📚 Learning Roadmap
- 💼 Job Role Recommendations
- 🔍 ATS-Friendly Resume Evaluation

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/aiza599/Ai-career-intellgence-Engine.git
```

Move into the project

```bash
cd Ai-career-intellgence-Engine
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```
